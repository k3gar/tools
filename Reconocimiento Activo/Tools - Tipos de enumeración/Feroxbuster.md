Feroxbuster es una herramienta de descubrimiento de contenido web rápida, recursiva y de código abierto, escrita en el lenguaje **Rust**. Está diseñada específicamente para realizar **navegación forzada** (forced browsing), lo que permite enumerar y acceder a recursos como directorios, archivos y endpoints que no están referenciados públicamente por la aplicación web pero siguen siendo accesibles.
